# Design reference notes

The current Kraken public site uses a light, airy base with strong black typography and electric purple accents. Its main cues are a compact navigation bar, restrained pill-shaped actions, a centered hero with a short headline, proof metrics beneath the primary action, and large dark feature panels that frame product screenshots. The visual language feels editorial and human rather than overly futuristic: fewer neon effects, clearer hierarchy, and more deliberate whitespace.

For BTE, use these cues as inspiration only and keep original branding/content: warm off-white page surfaces, ink-purple text, saturated violet primary actions, lilac secondary surfaces, rounded but not excessive cards, clear trust/disclosure copy, and a dark purple trading-console feature panel. Public navigation should stay simple. Admin should use a darker purple operations shell with a persistent sidebar, clear section groups, compact status badges, and calmer table density.

Reference: https://www.kraken.com/ (reviewed 2026-09-05).
